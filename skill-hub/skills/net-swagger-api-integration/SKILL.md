---
name: net-swagger-api-integration
description: "ใช้สำหรับเชื่อมต่อ จัดการ และเรียกใช้งาน .NET Web API ผ่านเอกสาร Swagger/OpenAPI เหมาะสำหรับใช้เมื่อต้องการดึงข้อมูลหรือเพิ่มทักษะ (Skills) เข้าสู่ระบบหลังบ้านที่เป็น .NET"
---

1. **การตรวจสอบโครงสร้าง API (Swagger Definition)**
   - ตรวจสอบ URL ของ Swagger JSON (เช่น `/swagger/v1/swagger.json`) เพื่อทำความเข้าใจ Endpoint และ Payload ล่าสุดของ .NET API

2. **การดึงข้อมูลทักษะทั้งหมด (Get All Skills)**
   - ส่งคำขอแบบ `GET` ไปยัง `/api/skills`
   - ใช้เมื่อต้องการแสดงรายการทักษะทั้งหมดที่มีอยู่ในระบบ

3. **การค้นหาทักษะตาม ID (Get Skill By ID)**
   - ส่งคำขอแบบ `GET` ไปยัง `/api/skills/{id}`
   - ใช้เมื่อต้องการดูรายละเอียดเจาะจงของทักษะชิ้นใดชิ้นหนึ่ง

4. **การเพิ่มทักษะใหม่ (Create Skill)**
   - ส่งคำขอแบบ `POST` ไปยัง `/api/skills` พร้อมแนบ JSON Body:
     ```json
     {
       "name": "ชื่อทักษะ",
       "description": "คำอธิบายทักษะ",
       "category": "หมวดหมู่"
     }
     ```
   - ใช้เมื่อต้องการสร้างทักษะใหม่เข้าสู่ระบบ

5. **การแก้ไขข้อมูลทักษะ (Update Skill)**
   - ส่งคำขอแบบ `PUT` ไปยัง `/api/skills/{id}` พร้อมแนบ JSON Body ที่มีข้อมูลอัปเดต:
     ```json
     {
       "id": 1,
       "name": "ชื่อทักษะที่แก้ไข",
       "description": "คำอธิบายใหม่",
       "category": "หมวดหมู่ใหม่"
     }
     ```
   - ใช้เมื่อต้องการปรับปรุงข้อมูลทักษะที่มีอยู่แล้ว

6. **การลบทักษะ (Delete Skill)**
   - ส่งคำขอแบบ `DELETE` ไปยัง `/api/skills/{id}`
   - ใช้เมื่อต้องการลบข้อมูลทักษะออกจากระบบตามรหัส ID ที่ระบุ
